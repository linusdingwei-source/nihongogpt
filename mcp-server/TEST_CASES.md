# NihongoGPT MCP Skill 测试用例

以下是用于验证 Skill 是否正确触发和执行的测试用例。每个用例包含用户输入示例和预期行为。

---

## 1. Skill 触发测试

验证不同的用户表述能否正确触发 nihongogpt-mcp skill。

### 1.1 直接关键词触发

| # | 用户输入 | 预期 |
|---|---------|------|
| 1 | "帮我创建一张日语闪卡" | 触发 skill，询问要创建卡片的日文内容 |
| 2 | "我想管理我的 NihongoGPT 卡片" | 触发 skill，询问具体操作 |
| 3 | "分析一下这段日语文本" | 触发 skill，准备调用 analyze_text |
| 4 | "生成日语发音音频" | 触发 skill，准备调用 generate_tts |

### 1.2 隐式意图触发

| # | 用户输入 | 预期 |
|---|---------|------|
| 5 | "这句话什么意思：今日は天気がいいですね" | 触发 skill，调用 analyze_text |
| 6 | "把这几个单词做成复习卡片：食べる、飲む、走る" | 触发 skill，批量调用 create_card |
| 7 | "我的日语牌组里有哪些卡片？" | 触发 skill，调用 list_decks + list_cards |

### 1.3 不应触发

| # | 用户输入 | 预期 |
|---|---------|------|
| 8 | "帮我写一个 Python 脚本" | 不触发 skill |
| 9 | "翻译这段英文" | 不触发 skill（非日语学习场景） |

## 2. 卡片管理测试

### 2.1 创建卡片

**用户输入**: "帮我用「彼女は毎朝六時に起きます」创建一张日语闪卡，放到 JLPT N5 牌组里"

**预期行为**:
- 调用 `create_card`
- 参数: `text: "彼女は毎朝六時に起きます"`, `deckName: "JLPT N5"`, `includePronunciation: true`
- 返回卡片信息，包含正面（日文）、背面（翻译+语法分析 HTML）、音频 URL
- 消耗 3 credits

### 2.2 创建不带发音的卡片

**用户输入**: "创建一张单词卡片：勉強，不需要发音"

**预期行为**:
- 调用 `create_card`
- 参数: `text: "勉強"`, `cardType: "单词"`, `includePronunciation: false`
- 消耗 2 credits

### 2.3 搜索卡片

**用户输入**: "搜索所有包含「食べる」的卡片"

**预期行为**:
- 调用 `list_cards`
- 参数: `search: "食べる"`
- 返回匹配的卡片列表和分页信息

### 2.4 更新卡片

**用户输入**: "把卡片 abc123 移到「N3语法」牌组，加上标签 grammar 和 te-form"

**预期行为**:
- 调用 `update_card`
- 参数: `id: "abc123"`, `deckName: "N3语法"`, `tags: ["grammar", "te-form"]`

### 2.5 删除卡片

**用户输入**: "删除卡片 abc123"

**预期行为**:
- 确认删除操作
- 调用 `delete_card`，参数: `id: "abc123"`

## 3. 牌组管理测试

### 3.1 创建牌组

**用户输入**: "创建一个新牌组叫「JLPT N3 文法」，描述是 N3 级别语法练习"

**预期行为**:
- 调用 `create_deck`
- 参数: `name: "JLPT N3 文法"`, `description: "N3 级别语法练习"`, `isPublic: false`

### 3.2 列出所有牌组

**用户输入**: "显示我所有的日语牌组"

**预期行为**:
- 调用 `list_decks`
- 展示牌组名称、卡片数量等信息

### 3.3 查看牌组详情（含卡片）

**用户输入**: "显示牌组 deck123 里的所有卡片"

**预期行为**:
- 调用 `get_deck`
- 参数: `id: "deck123"`, `includeCards: true`
- 展示牌组信息及其中的卡片列表

### 3.4 删除牌组

**用户输入**: "删除牌组 deck123"

**预期行为**:
- 提醒用户牌组内的卡片会被保留但变为未分配
- 确认后调用 `delete_deck`

## 5. 文本分析测试

**用户输入**: "帮我分析一下这句日语：彼女に本をあげました"

**预期行为**:
- 调用 `analyze_text`，参数: `text: "一所懸命"`
- 展示含义、读音、用法

## 6. TTS 语音测试

### 6.1 基础 TTS

**用户输入**: "生成「おはようございます」的发音音频"

**预期行为**:
- 调用 `generate_tts`，参数: `text: "おはようございます"`
- 返回 base64 MP3 音频
- 消耗 1 credit

### 6.2 增强 TTS（带时间戳）

**用户输入**: "生成「東京タワーは東京都港区にあります」的发音，需要逐词时间戳"

**预期行为**:
- 调用 `generate_tts_enhanced`
- 参数: `text: "東京タワーは東京都港区にあります"`, `includeTimestamps: true`
- 返回 audioUrl 和 timestamps 数组

## 7. 组合工作流测试

### 7.1 分析后创建卡片

**用户输入**: "分析「雨が降りそうだから、傘を持って行った方がいいよ」，然后帮我做成闪卡放到文法牌组"

**预期行为**:
1. 调用 `analyze_text` 分析句子
2. 展示分析结果给用户
3. 调用 `create_card`，参数: `text: "雨が降りそうだから、傘を持って行った方がいいよ"`, `deckName: "文法"`

### 7.2 批量创建卡片

**用户输入**: "帮我把这些句子都做成卡片：1. 猫が好きです 2. 犬が嫌いです 3. 鳥を飼っています，放到「动物」牌组"

**预期行为**:
1. 先尝试调用 `list_decks` 确认"动物"牌组是否存在
2. 如不存在，调用 `create_deck` 创建
3. 依次调用 3 次 `create_card`，每次指定 `deckName: "动物"`
4. 汇总结果，报告消耗的总 credits

### 7.3 整理现有卡片

**用户输入**: "帮我把所有包含「て形」的卡片移到「N4语法」牌组"

**预期行为**:
1. 调用 `list_cards`，参数: `search: "て形"`
2. 展示搜索结果，确认要移动的卡片
3. 对每张卡片调用 `update_card`，设置 `deckName: "N4语法"`

## 8. 错误处理测试

### 8.1 Credits 不足

**用户输入**: "创建一张卡片：すみません"

**预期行为**（当 credits 不足时）:
- 调用 `create_card` 返回 `INSUFFICIENT_CREDITS` 错误
- 告知用户需要在 NihongoGPT 平台购买更多 credits

### 8.2 卡片不存在

**用户输入**: "查看卡片 nonexistent123 的详情"

**预期行为**:
- 调用 `get_card` 返回 `NOT_FOUND`
- 提示用户该卡片不存在

### 8.3 未认证

**预期行为**（当 API Key 未配置或失效时）:
- 返回 `UNAUTHORIZED` 错误
- 提示用户检查 MCP server 的环境变量配置
